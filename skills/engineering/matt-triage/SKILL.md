# Triage

Move tracker issues through triage state machine.

External pull requests (if enabled in issue-tracker config) = issues with attached code. Apply identical roles, states & machine. Resolve bare `#42` to issue or PR per config.

Start every tracker comment/issue with mandatory AI disclaimer:

```markdown
> *This was generated by AI during triage.*
```

## Reference docs

- [AGENT-BRIEF.md](AGENT-BRIEF.md): durable agent briefs
- [OUT-OF-SCOPE.md](OUT-OF-SCOPE.md): `.out-of-scope/` knowledge base

## Roles

**Category** roles:

- `bug`: broken behavior
- `enhancement`: new feature / improvement

**State** roles:

- `needs-triage`: maintainer evaluation needed
- `needs-info`: waiting on reporter
- `ready-for-agent`: fully specified + ready for AFK agent
- `ready-for-human`: manual human implementation required
- `wontfix`: rejected / already implemented

PR variations:
- `ready-for-agent`: agent executes next step on existing diff.
- `ready-for-human`: manual human merge required.

Require exactly 1 category + 1 state per issue. Conflicting states => halt & ask maintainer.

Names = canonical roles. Map to tracker label strings via `/matt-skill-setup` output. Missing mapping => prompt user to run `/matt-skill-setup`.

Transitions: Unlabeled => `needs-triage`. `needs-info` + reporter reply => `needs-triage`. Maintainer override always available. Unusual transitions => halt & ask.

## Invocation

Maintainer invokes `/triage` + natural language request. Interpret & act. Examples:

- "Show me anything that needs my attention"
- "Let's look at #42" (issue or PR)
- "Move #42 to ready-for-agent"
- "What's ready for agents to pick up?"

## Show what needs attention

Query issue tracker. Present 3 chronological buckets (oldest first):

1. **Unlabeled**: zero triage history.
2. **`needs-triage`**: active evaluation.
3. **`needs-info` + new reporter activity**: requires re-evaluation.

Include external PRs (if configured). Tag lines `[PR]` or `[issue]`. Restrict PR discovery to *external* authors. Collaborator PRs = internal work (skip discovery). Explicit PR request => bypass external filter.

Show item counts + 1-line summaries. Prompt maintainer selection.

## Triage specific issue or PR

1. **Gather context.** Read full issue/PR (body, comments, labels, author, dates, diff). Parse prior triage notes. Search codebase via domain glossary. Respect local ADRs. Run codebase checks:
   - **Redundancy**: search domain concepts for existing implementation. Found => `wontfix` (step 5).
   - **Prior rejection**: read `.out-of-scope/*.md`. Found match => surface to maintainer.
2. **Recommend.** Suggest category + state. Provide reasoning + codebase summary. Wait for maintainer direction.
3. **Verify claim.** Validate before matt-grilling. Bug => reproduce from steps. PR => checkout diff & run tests. Output: confirmed (with code path), failed, or insufficient detail (`needs-info`). Confirmed verification => strong agent brief.
4. **Grill (conditional).** Weak request => invoke Skill tool twice (`matt-grilling` & `matt-domain-modeling`). Grill via sequential questions. Sharpen domain terms. Update `CONTEXT.md` & ADRs inline.
5. **Apply outcome:**
   - `ready-for-agent`: post agent brief ([AGENT-BRIEF.md](AGENT-BRIEF.md)).
   - `ready-for-human`: post agent brief + manual delegation reason (judgment calls, access, design, manual testing).
   - `needs-info`: post triage notes (template below).
   - `wontfix`: close issue. Comment depends on reason:
     - **Already implemented**: point to existing code. Skip `.out-of-scope/` write.
     - **Rejected (bug)**: post polite explanation + close.
     - **Rejected (enhancement)**: write `.out-of-scope/` file + post link + close ([OUT-OF-SCOPE.md](OUT-OF-SCOPE.md)).
   - `needs-triage`: apply role. Add optional progress comment.

## Quick state override

Target: explicit maintainer command ("move #42 to ready-for-agent").
Trust maintainer. Apply role directly. Skip matt-grilling. Confirm intended actions (role changes, comment, close) + execute. Target `ready-for-agent` => ask maintainer to write agent brief.

## Needs-info template

```markdown
## Triage Notes

**What we've established so far:**

- point 1
- point 2

**What we still need from you (@reporter):**

- question 1
- question 2
```

Include all matt-grilling resolutions under "established so far". Require specific actionable questions. Skip generic "provide more info" requests.

## Resuming previous session

Target: issue/PR with prior triage notes.
Read notes. Check reporter answers. Present updated context. Skip resolved questions.
